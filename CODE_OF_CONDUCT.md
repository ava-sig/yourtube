# Code of Conduct

YourTube welcomes constructive participation from people with different backgrounds and experience levels.

Participants are expected to:

- Be respectful and discuss the work rather than attack people.
- Give actionable feedback and accept good-faith corrections.
- Avoid harassment, discrimination, threats, doxxing, and unwanted personal contact.
- Respect privacy: do not publish another person's library data, viewing history, account details, or credentials.

Project maintainers may edit or remove contributions that violate these expectations and may restrict participation when needed to keep the project safe and useful. Report conduct concerns privately to the project maintainer through GitHub rather than posting personal information in a public issue.
